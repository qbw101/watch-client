设计说明（HarmonyOS 图标规范）

  • 分层结构：背景层 + 前景层各 512×512，由系统套用遮罩（手机超椭圆 / 手表圆形），前景主体收在中央安全区内，任何裁切都不伤主体。
  • 配色：深墨底 #0B0E15（OLED 省电）+ 左上品红 / 右下青的环境微光（呼应抖音品牌双色系）；气泡渐变 #FF6B87 → #B06CFF → #5B8CFF，比旧版粉灰更通透。
  • 图形延续：保留旧版「气泡小精灵」造型与双眼负形，老用户一眼认出；顶部加了一道柔和高光，小尺寸下轮廓更清晰。
  • 小尺寸可读性：双眼与气泡边缘对比度高，36px 下仍可辨认（见上方预览）。
  • 落盘文件：foreground.png / background.png（512，分层图标）· app_icon.png / startIcon.png（216，圆角平面）。旧版备份在 attic/icons-v0/。
