2触控热区检查

在所有可点元素上叠加描边与实测尺寸，逐个核对是否达到防误触标准。
达标（高 ≥ 88px） 图标钮（≥ 64px，孤立法） 不达标

3设计规范要点

  • 主操作按钮高 ≥ 96px（重试 / 保存 / 回复），常规列表行与按钮 ≥ 88px，纯图标圆钮 ≥ 64px 且同屏孤立、间距 ≥ 8px。
  • 圆屏安全区：内容列宽 ≤ 331px（1.42r，r=233px），四角不摆放任何可点元素。
  • 字号下限：正文 ≥ 24px，辅助 ≥ 20px，最小 18px；标题 26–30px。
  • 深色底 #000（OLED 省电），卡片 #1C1C1E，主色鸿蒙蓝 #0A84FF，品牌红 #FE2C55 仅作点缀。
  • 每屏一个主操作，固定在底部拇指热区（全宽胶囊，宽 300–331px）。
  • 图标一律用绘制图形或汉字（返/刷/设），不依赖生僻符号字形——真机字体会渲染成空白。
  • 滚动以滑动 + 旋转表冠为主，可滚列表首尾给出「旋转表冠查看更多」提示。
